# Teach mode piece 2 (#382): login methods, player, registry — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A recording becomes a typed login method with one command; the owner imports it into a per-broker registry; a fill on that site runs the method's steps (pre-checked, forced submit and scrub at `milliseconds`) and stops on drift.

**Architecture:** `kharon-recording` gains the `LoginMethod` format and the pure conversion. `kharond` gains a `teach` module (registry file, import checks) and a method path through the existing fill engine: the engine asks a `MethodSource` for the site's method after it reads the live origin, and the one in-page call does the pre-check, the writes and the submit. Owner ops go over the owner socket and the `kharon` CLI. No new CDP subscription, no new agent tool.

**Tech Stack:** Rust 2024, serde (typed structs only, never `json!`/`Value` in new code we own), tokio, clap, node (in-page harness), Chromium (CI).

**Spec:** `docs/superpowers/specs/2026-11-24-teach-method-design.md`. Read it before any task. Where this plan decides something the spec left to the builder, the plan wins; where they disagree otherwise, stop and report.

## Global Constraints

- New data we own is typed `serde` structs/enums. No `serde_json::json!` and no `serde_json::Value` in new code, except where an existing function's signature already takes `Value` (the CDP `session.request` params): build a typed `Serialize` struct and convert with `serde_json::to_value` at that boundary.
- A method, the registry, a reply, an audit entry and any log line hold no value, no value length and no page text.
- No `Runtime`, `Log`, `Network` or `Page` event subscription in kharond (REQ-ARCH-003). The player is the existing one in-page call plus the loader re-read.
- Fill replies: fixed status and fixed `&'static str` detail only. New outcomes reuse status `field_not_found`.
- `kharon-recording` keeps no browser I/O. It may gain `sha2`. `kharon-teach` depends on nothing in `kharond`.

## Shared decisions (every task relies on these)

**Step index.** A method's steps are numbered from 0 across its legs in order (leg 0's steps, then leg 1's). Drift reports, audit entries and `kharon teach override` use that number.

**Which fills a method governs.** A fill whose requested kinds include `username` or `password`, on a page whose site has a registry entry. A TOTP-only fill never consults the registry. The leg decides what is written: a requested kind the leg has no fill step for is not sent to the page and is absent from `fields_filled`; a role the leg needs that was not requested ends the fill before any value is sent.

**Forced submit.** `force = method.rung == Milliseconds || method.shape is TwoStep`. When `force`, the fill submits with the leg's submit whatever the request said. Otherwise the request's `submit` decides, and when true the leg's submit is used. The post-submit scrub is forced on when `force` and the leg has a password step; otherwise the plan's own `post_submit_scrub` stands.

**New fill details** (all status `field_not_found` unless noted): `method_wrong_page`, `method_drift`, `method_not_ready`, `method_stale`, `method_field_not_requested`; and `method_selectors` on a `filled` method fill whose request carried at least one selector.

**Site key.** `kharond::teach::site_key(host)`: the registrable domain from `crate::origin::registrable_domain`, except that an IP literal, `localhost` or any host the list gives no answer for is its lowercased self. Same answers as `kharon_teach::site::registrable_domain`.

**In-page leg argument** (7th argument of `fillInPage`, `null` for a normal fill). `fields[i]` is the value for `leg.fills[i]`; in leg mode `fields[i].selector` is ignored.

```text
leg = {
  path: "/login",
  fills: [ { index: 1, selectors: ["#pw", "input[name=pass]"], password: true,
             expect: { tag: "input", input_type: "password", id: "pw", name: "pass", autocomplete: null } } ],
  submit: null | { index: 2, via: "form" | "enter" | "click", selectors: [...], expect: {...} | null }
}
```

In-page failure codes in leg mode: `method_wrong_page`, `method_drift:<index>`, `method_not_ready:<index>`.

## Review Focus

1. **A method fill whose request names only `password` on leg 1 of a two-step login** (leg needs `username`). Expected: `field_not_found` / `method_field_not_requested`, nothing sent, grant use returned. Test in Task 6.
2. **A selector in a method or override that is not valid CSS** (`querySelectorAll` throws). Expected: that candidate is skipped; if none resolves, `method_drift`, not an `error`. Test in Task 4.
3. **A registry file left group- or world-readable, or holding an unknown `format_version`.** Expected: the daemon refuses to start with a named error rather than using or rewriting it. Test in Task 5.
4. **A method file larger than the owner socket's request cap.** Expected: `kharon teach import` says the file is too large before it sends anything, not an opaque `bad_request`. Test in Task 9.
5. **A site on an IP or `localhost`** (every loopback test, and intranet logins). Expected: the registry key is the host itself and lookup works. Tests in Tasks 5 and 10.

```rust
pub const METHOD_FORMAT_VERSION: u32 = 1;
pub const METHOD_FILE_SUFFIX: &str = ".kharon-method.json";

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct LoginMethod { pub format_version: u32, pub site: Site, pub shape: Shape, pub rung: Rung,
    pub legs: Vec<Leg>, pub success: SuccessCheck, pub provenance: Provenance }
pub struct Site { pub domain: String, pub origin: String, pub path: String }        // origin = scheme://host[:port]
#[serde(rename_all = "snake_case")] pub enum Rung { Milliseconds, AgentContinues }   // Copy, Eq
pub struct Leg { pub steps: Vec<MethodStep> }
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum MethodStep {
    Navigate { path: String },
    Fill { role: FillRole, selectors: Vec<String>, expect: Expected },
    Submit { via: SubmitVia },
}
#[serde(rename_all = "snake_case")] pub enum FillRole { Username, Password }         // Copy, Eq
pub struct Expected { pub tag: String, pub input_type: Option<String>, pub id: Option<String>,
    pub name: Option<String>, pub autocomplete: Option<String> }
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum SubmitVia { Form, Enter, Click { selectors: Vec<String>, expect: Expected } }
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum SuccessCheck { PathChangedTo { path: String }, PasswordFieldGone, None }
#[serde(tag = "source", rename_all = "snake_case")]
pub enum Provenance {
    Recording { sha256: String, tool_version: String, browser_product: String,
                listener_world: ListenerWorld, rung_ceiling: RungCeiling },
    HandWritten { author: String },
}
#[derive(Debug, thiserror::Error)]
pub enum MethodError {
    #[error("unsupported method format_version {0}")] UnsupportedVersion(u32),
    #[error("not a kharon login method: {0}")] Parse(#[from] serde_json::Error),
    #[error("not a usable login method: {0}")] Invalid(&'static str),
}
impl LoginMethod {
    pub fn to_json(&self) -> String;                       // pretty, trailing newline, always writes METHOD_FORMAT_VERSION
    pub fn from_json(text: &str) -> Result<Self, MethodError>;   // version probe, parse, then validate()
    pub fn validate(&self) -> Result<(), MethodError>;
    pub fn steps(&self) -> impl Iterator<Item = (u32, usize, &MethodStep)>;  // (flat index, leg index, step)
    pub fn digest(&self) -> Option<&str>;                  // provenance sha256, None for hand-written
}
```

All structs and the two tagged-by-field enums use `#[serde(deny_unknown_fields)]`, so a stray `value_len` or `placeholder` in a hand-edited file is a parse error.

`validate()` returns `Invalid(reason)` with these fixed reasons: `shape` is `Unrecognized` → `"shape"`; `legs` empty, or `TwoStep` without exactly 2 legs, or any other shape without exactly 1 → `"legs"`; a leg whose first step is not `Navigate`, that has no `Fill`, or whose `Submit` count is not 1 or is not last → `"leg_steps"`; no `Fill` with role `Password` in the last leg → `"no_password"`; a `Fill` or `Click` with no selector, an empty selector or one over 1024 bytes → `"selector"`; a password `Fill` whose `expect.input_type` is not `Some("password")` → `"password_type"`; any path (`site.path`, each `Navigate`, `PathChangedTo`) that does not start with `/`, starts with `//`, or contains `?`, `#` or a control character → `"path"`; `site.origin` not `http://` or `https://` followed by a non-empty host[:port] with no `/`, `?`, `#` or `@` → `"origin"`; `site.domain` empty → `"domain"`; `site.path` different from leg 0's `Navigate` path → `"site_path"`.

**Produces:**

```rust
#[derive(Debug, Clone, Copy, Default)]
pub struct ConvertOptions { pub allow_unconfirmed: bool, pub success: Option<SuccessOverride> }
#[derive(Debug, Clone, Copy, PartialEq)] pub enum SuccessOverride { PathChanged, PasswordFieldGone, None }
#[derive(Debug, PartialEq, thiserror::Error)]
pub enum NotConvertible {
    #[error("kharon cannot tell how this login works; a person has to write the method by hand")] NeedsPerson,
    #[error("a credential field sits in a shadow root, which a fill cannot reach; write the method by hand")] InShadowRoot,
    #[error("no submit was recorded after the last field of a step")] NoSubmit,
    #[error("nobody confirmed that this login worked; pass --unconfirmed to convert it anyway")] Unconfirmed,
    #[error("the recording does not match its own classification")] ShapeMismatch,
}
impl LoginMethod {
    /// `domain` is the registrable domain of the login origin; the caller computes it (this crate has no PSL).
    pub fn from_recording(rec: &Recording, recording_bytes: &[u8], domain: &str, opts: ConvertOptions)
        -> Result<LoginMethod, NotConvertible>;
}
```

Rules (only main-frame steps are read; a step with `frame.main == false` is ignored):
1. `Unconfirmed` when `!rec.success_confirmed && !opts.allow_unconfirmed`.
2. `NeedsPerson` when the shape is `Unrecognized`, or `Transformed { digest: None }`, or `rung_ceiling` is `NeedsPerson`.
3. Credential steps are `Step::Input` with `role` `Username` or `Password`, in order. `InShadowRoot` if any has `element.in_shadow_root`.
4. Legs: start a new leg at a credential step when a main-frame `Step::Navigation` with a different path lies between it and the previous credential step. A leg's `Navigate` path is the path of the last main-frame `Navigation` before its first credential step, or `start_url.path` if none. `ShapeMismatch` if the count is not 2 for `TwoStep` or not 1 otherwise, if there is no password step in the last leg, or if any leg's navigation origin differs from `start_url.origin`.
5. Submit for a leg: look at the steps after its last credential step and before the next main-frame `Navigation` to a different path (or the end). If a `Step::Submit` is there → `Form`. Else if a `Step::EnterKey` → `Enter`. Else among the `Step::Click`s, the first whose element is `tag == "button"` or `input_type` in `submit|button|image`, else the first click → `Click` (shadow-root click element → `InShadowRoot`). None → `NoSubmit`.
6. `Expected` and `selectors` are copied from the `ElementDescriptor` (`tag`, `input_type`, `id`, `name`, `autocomplete`, `selectors`). Nothing else is copied from it. A fill with no selector → `ShapeMismatch`.
7. `rung`: `Milliseconds` for ceiling `Milliseconds`, `AgentContinues` for `AgentContinues`.
8. `success`: `opts.success` if set (`PathChanged` needs a `final_url`, else `ShapeMismatch`); otherwise `PathChangedTo { final_url.path }` when `final_url` exists and its path differs from the last leg's path, else `None`.
9. `site`: `domain` as given, `origin` = `start_url.origin`, `path` = leg 0's path. `provenance`: lowercase-hex SHA-256 of `recording_bytes`, `rec.tool_version`, `rec.browser.product`, `rec.listener_world`, `rec.classification.rung_ceiling`.
10. The result passes `validate()` (map a failure to `ShapeMismatch`).

1. `plan.method_source` is `None`, or no requested kind is `Username`/`Password`, or `lookup(&info.url)` is `None` → today's path, untouched.
2. Otherwise this is a method fill. `selectors_ignored` = any plan field has a selector. If `lookup.stale` → record the note with `Stale`, return `MethodStale`.
3. `prepare`: pick the leg whose `Navigate` path equals the live URL's path; none → `WrongPage`. `order` is the leg's fill roles in order as `FieldKind`s; a role not in `requested` → `FieldNotRequested`. Selector lists are the entry's overrides for that step index followed by the method's own. `submit`/`scrub` per Shared decisions (`has_password` gates the forced scrub). 4. Build `field_args` from the plan's fields in `order` only (selector `null`), and the leg argument; call the in-page function with `submit` and `scrub` from `Prepared`. The 7th argument is `null` on the normal path.
5. Map in-page exceptions: `kharon:method_wrong_page` → `MethodWrongPage` / `WrongPage`; `kharon:method_drift:<n>` → `MethodDrift { step: n }` / `Drift`; `kharon:method_not_ready:<n>` → `MethodNotReady` / `NotReady`.
